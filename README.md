# Penna_Conversor-
Conversor desktop Windows que transforma planilhas Excel em TXT fiscais APAC-MAG do SIA/SUS: valida consistência RCONSIST e regras SIGTAP (download automático da base do mês), gera fichas do paciente em PDF e o pacote de remessa. Interface gráfica com arraste-e-soltar; o cliente não precisa de Python.
